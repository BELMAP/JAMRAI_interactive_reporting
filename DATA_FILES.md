# Data files used in the R scripts

This catalogs every data file (CSV/XLSX/GZ) touched by the R scripts in this repo: where it comes from, what it contains, and which script reads or writes it. Generated by inspecting `read_csv`/`read.csv`/`write_csv` calls across all tracked `.R` files.

## Pipeline overview

```
collecting_cleaning_data.R  ─┐
                              ├─> Data/combined_data_for_analysis.csv ─┐
making_animal_mgkg_data.R    ├─> Data/Animal_mg_kg.csv                 │
making_human_mgkg_data.R  ───┼─> Data/Human_mg_kg.csv                  ├─> run_trend_analyses.R ─┐
                              └─> Data/JIACRA_historic_human.csv       ┘                          │
                                                                                                    ├─> AMR_data_and_GLM_predictions_revised_method.csv ─┐
                                                                                                    └─> AMC_human_results.csv, AMC_vet_results.csv ──────┤
                                                                                                                                                          ├─> src/data.R ──> app.R (Shiny app)
                                                                                       Data/contributor_report_details.csv ───────────────────────────────┘
```

## Human AMR / AMC surveillance data

| File | Description | Source | Used in |
|---|---|---|---|
| `Data/ECDC_surveillance_data_Antimicrobial_resistance.csv` | Raw ECDC/EARS-Net human AMR surveillance export (resistance % by pathogen, antimicrobial, country, year) | External download from ECDC (per README instructions) | Loaded by `collecting_cleaning_data.R` → filtered/reshaped into `ECDC_data_BE` / `ECDC_data_EU` |
| `Data/combined_data_for_analysis.csv` | Combined human (ECDC) + animal (EFSA) AMR dataset, one row per pathogen/antimicrobial/region/host/year | **Written** by `collecting_cleaning_data.R` (`AMR_comparative_interactive`) | Loaded by `run_trend_analyses.R` as `AMR_comparative_interactive`, the input to the GLM trend loop |
| `Data/Consumption_data/AMC_export_table_BE.CSV` | Belgian human antimicrobial consumption export: year, ATC code, class, tonnes | External download (national AMC export) | Loaded by `making_human_mgkg_data.R` as `Human_AMC_raw` |
| `Data/Consumption_data/demo_pjan_Eurostat_pop_BE.csv` | Eurostat Belgian population by age, sex, year | External download (Eurostat `demo_pjan`) | Loaded by `making_human_mgkg_data.R` as `Human_pop_size` |
| `Data/Consumption_data/EFSA_av_human_bodyweight.csv` | Average human bodyweight (kg) by age and sex, semicolon-separated | External source (EFSA/JIACRA methodology reference table) | Loaded by `making_human_mgkg_data.R` as `human_BW_av`, joined with population to compute biomass |
| `Data/Human_mg_kg.csv` | Belgian human AMC expressed as mg/kg biomass, by year | **Written** by `making_human_mgkg_data.R` (`human_amc_mgkg`) | Loaded by `run_trend_analyses.R` as `AMC_human` |
| `Data/Consumption_data/jiacra_amc_mgkg.csv` | 2012 JIACRA report: human & animal mg/kg consumption by EU country | External download (JIACRA report data) | Loaded by both `making_animal_mgkg_data.R` and `making_human_mgkg_data.R` as `JIACRA_2012` |
| `Data/JIACRA_historic_human.csv` | Historic (2012–2021) EU human mg/kg consumption by country, combined from JIACRA report tables | **Written** by `making_human_mgkg_data.R` (`JIACRA_historic_human`) | Loaded by `run_trend_analyses.R` as `JIACRA_historic_human` |
| `AMC_human_results.csv` (repo root) | Belgium human AMC mg/kg trend result with direction icon + significance stars, ready for the app's AMC module | Intended to be **written** by `run_trend_analyses.R` (`AMC_human_result`) — but that `write.csv(...)` call is currently commented out (lines ~511–513) -- uncomment this to regenerate | Loaded by `src/data.R` as `Human_AMC` |

## Model output / app metadata

| File | Description | Source | Used in |
|---|---|---|---|
| `AMR_data_and_GLM_predictions_revised_method.csv` (repo root) | Per-category Poisson/negative-binomial trend predictions, confidence intervals, and trend icon/significance — one block of rows appended per AMR category | **Written (appended)** by `run_trend_analyses.R`'s model loop | Loaded by `src/data.R` as `comparative_AMR_data_raw`, the main dataset behind the AMR module in the Shiny app |
| `AMR_GLM_predictions/GLM_predictions<category>revised_method.csv` (one file per AMR category, ~300+ files) | Per-category model prediction table (same content that gets appended into the file above) | **Written** by `run_trend_analyses.R` | Diagnostic/audit output only — not read back by any script |
| `AMR_GLM_output_summaries/GLM_output_<category>revised_method.txt` (one file per AMR category) | Text log of the model fit, dispersion tests, and diagnostics for each category | **Written** by `run_trend_analyses.R` (`capture.output(...)`) | Diagnostic/audit output only — not read back by any script |
| `Data/contributor_report_details.csv` | Contributor/report metadata (semicolon-separated) used to attribute data in the app | External/manually maintained reference file | Loaded by `src/data.R` as `contributor_list` |

## Files present but not currently loaded by any script

| File | Notes |
|---|---|
| `Data/Consumption_data/demo_pjan__custom_21792359_linear.csv.gz` | Compressed Eurostat population extract;  the raw source/backup for `demo_pjan_Eurostat_pop_BE.csv`. Not referenced by any script. |
| `Data/Consumption_data/esvac_sales_food_producing_animals_2010_2022.csv` | ESVAC sales data 2010–2022. Not referenced by any script — superseded by `esuavet_food_animal_sales_2023_2024.csv` but reserved for a future extension of the historic series. |
| `Data/Consumption_data/ESVAC_all_years_pcu.csv` | ESVAC population correction unit (PCU) reference data. Not referenced by any script. |
| `www/AMR - 2025 Interactive dashboard_BE_MRSA.csv` | Same format as the other "AMR - 2025" dashboard exports, but for MRSA. `load_all_amr_2025()` only scans `Data/`, not `www/`, and there's no matching `EU_MRSA` file, so this file isn't currently picked up. |
| `Data/trying_to_scrape_additional_EFSA_data/**` (PDFs, `.xlsm`/`.xlsx` annexes, and ~290 CSVs under `csv_export/`) | Working files from an EFSA "Annex C/D/E" PDF/Excel scraping experiment. `load_data.R` does define a loader (`process_csv` / `amr_data`) that reads from `here("..", "csv_export")` — but that resolves to a `csv_export` folder **one level above the project root**, not to this tracked `Data/trying_to_scrape_additional_EFSA_data/csv_export/` folder. As configured, `load_data.R` does not actually load these tracked files; likely a leftover path from when the script lived elsewhere, or the script expects a different local layout. |

## Notes

- `install_requirements.R` and `src/setup.R` don't read or write any data files — they only manage package installation/loading.
- `AMC_human_results.csv` and `AMC_vet_results.csv` are consumed by the live app but their generating `write.csv()` calls in `run_trend_analyses.R` are commented out — to regeneration uncomment lines ~511–513 and ~582, if the underlying AMC data changes.
